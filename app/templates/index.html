About NETRADEEP

AI-powered clinical diagnostic platform for diabetic retinopathy detection

Platform Overview

NETRADEEP is an end-to-end clinical AI platform designed to assist ophthalmologists in the automated grading of diabetic retinopathy from fundus photographs. The platform employs a fine-tuned MobileNetV2 deep learning model trained on the EyePACS/APTOS dataset and provides explainable AI outputs via Gradient-weighted Class Activation Mapping (Grad-CAM).

The system produces multi-class severity grading across 5 clinically recognized stages (0–4) following the International Diabetic Retinopathy Severity Scale. All predictions include per-class confidence scores and heatmap overlays.

Technical Architecture

The diagnostic pipeline consists of a Python/Flask REST API backend, a single-page web application frontend, and an SQLite-based Electronic Health Record module. Preprocessing uses CLAHE on the green channel of the fundus image to improve microaneurysm visibility.

Explainability is provided through Grad-CAM heatmaps generated against the final convolutional layer of MobileNetV2, visualizing the discriminative regions used by the model during classification.

Clinical Disclaimer

NETRADEEP is intended as a clinical decision support tool only. All AI-generated results must be reviewed and validated by a qualified ophthalmologist or medical professional before any clinical action is taken. This system does not constitute a substitute for professional medical examination, diagnosis, or treatment.
